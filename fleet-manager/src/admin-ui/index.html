Grants

One secret, any number of machines. Every shipper you hand it to enrolls as its own install, until the grant expires or you revoke it.

IDExpiresStatus
Active
Accepts enrollments until it expires.
Expired
Past its expiry. Enrollment is refused; create a new grant.
Revoked
Switched off by an administrator. Enrollment is refused permanently.
Actions
Revoke
Stops the grant enrolling any more shippers. Permanent — shippers already enrolled with it keep working.

No grants yet. Create a grant to enroll multiple machines.

Enroll one or more shippers with this grant:

quesma-shipper login --server  <grant>

Replace <grant> with the secret shown after creation.

Invites

One secret, one machine. The first shipper to enroll spends it; no second machine can use it.

IDExpiresStatus
Active
Unused. The first machine to enroll claims it.
Reserved
A machine has claimed it and is finishing enrollment. Only that machine can complete it; Release hands the invite back.
Spent
Enrollment completed. It cannot enroll a second machine.
Expired
Past its expiry with no machine claiming it.
Revoked
Switched off by an administrator. Enrollment is refused permanently.
Actions
Revoke
Stops the invite being used. Permanent.
Release
Clears a reservation so the invite can go to another machine. Only offered while it is Reserved, and only accepted once the claiming install is revoked or was never created.

No invites yet. Create an invite to enroll one machine.

Enroll one shipper with this invite:

quesma-shipper login --server  <invite>

Replace <invite> with the secret shown after creation.
